# Glossa

Экранный словарь для игр под Windows. Наводишь курсор на слово в игре, жмёшь **Alt+Q** — рядом открывается карточка:
статьи словарей сразу, а следом перевод слова и всей реплики по контексту от локальной языковой модели. Языки
текста — английский, японский, китайский; язык перевода — русский. Работает без интернета, мат и сленг переводит
как есть, с тем же регистром.

Слова копятся в «Словаре» вместе с кадром из игры и репликой, откуда они взяты, и уходят в Anki.

## Возможности

- **Поиск слова на экране:** снимок экрана → распознавание текста (PP-OCRv5) → слово под курсором и его реплика →
  карточка поверх игры, фокус у игры не отбирается.
- **Японский и китайский:** границы слов, словарная форма и чтение (UniDic), пиньинь с тонами (CC-CEDICT), фразы
  и устойчивые выражения по словарям.
- **Справочники:** каталог с установкой из программы (Warodai, JMdict, БКРС, CC-CEDICT, Wiktionary) и уровни
  JLPT / HSK 3.0 / CEFR; импорт своих словарей — DSL, StarDict, MDX, Yomitan.
- **Перевод по контексту:** локальная модель через [llama.cpp](https://github.com/ggml-org/llama.cpp) или своё API
  (OpenAI-совместимые, Anthropic, OpenRouter, DeepSeek, Gemini, LM Studio, Ollama; ключи шифруются DPAPI).
- **Игры:** профиль на каждую игру, стоп-кадр для игр с захватом курсора, пауза игры на время карточки (не для
  игр с античитом), кнопки мыши 4/5, геймпады (XInput, DualSense, DualShock 4, Switch Pro).
- **Нагрузка:** модель выгружается без дела и уступает видеопамять игре, низкий приоритет процессов.
- **Словарь и Anki:** коллекции (ручные и по фильтру), экспорт `.apkg`, AnkiConnect, Quizlet, CSV; озвучка
  голосами Windows.
- Тёмная, светлая и «Диско» темы.

## Модели и движок

Модели и llama.cpp не входят в сборку — они скачиваются из программы: **Настройки → ИИ и модели → «Скачать»**.
Каждый файл закреплён за версией и контрольной суммой SHA-256, прерванная загрузка продолжается с места.

| Модель | Файл | Видеопамять |
|---|---|---|
| Gemma 4 26B A4B (по умолчанию) | [UD-IQ4_XS, 13,4 ГБ](https://huggingface.co/groxaxo/Huihui-gemma-4-26B-A4B-it-abliterated-GGUF) | ~13 ГБ, в режиме «минимум» ~3 ГБ |
| Gemma 4 12B | [Q4_K_M, 7,4 ГБ](https://huggingface.co/culturerevolt/gemma-4-12b-heretic-abliterated-GGUF) | ~7 ГБ |
| Gemma 4 E4B — для слабых ПК | [Q4_K_M, 5,3 ГБ](https://huggingface.co/TrevorJS/gemma-4-E4B-it-uncensored-GGUF) | ~3 ГБ |
| Своя модель | любой GGUF-файл | — |

Движок — официальный релиз llama.cpp (b11243): для NVIDIA — сборка CUDA 13.4 (карты Turing и новее, драйвер 580+),
для остальных видеокарт — Vulkan. Программа предлагает подходящую сама.

## Сборка

Нужны Windows 10/11 x64 и [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```
dotnet build src/Glossa.App
dotnet test src/Glossa.Tests
```

`tools/publish.ps1` собирает Release и ставит копию в `D:\Programs\Glossa` с ярлыком на рабочем столе.

Данные программы лежат в `D:\GlossaData` (другое место — переменная окружения `GLOSSA_DATA`). Пока без мастера
первого запуска туда нужно положить:

- модели распознавания — `tools/export_ocr_models.py` (берёт их из Python-пакета `rapidocr`);
- UniDic для японского — содержимое пакета `unidic-lite` в `dict\unidic-lite`.

Справочники, модели и llama.cpp ставятся из программы.

`glossa-cli` (`src/Glossa.Cli`) — то же без окна: установка и проверка словарей, загрузка llama.cpp, прогон
перевода на наборе реплик.
